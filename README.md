# SlideyDock16

A horizontally scrolling iPhone dock made and tested on **iOS 16 rootless** but may work with other iOS versions.



- Adjustable Dock Capacity: Choose between 4, 5 or 6 visible Dock icons without restricting the total number of apps.
- Up to 100 Apps: Add up to 100 apps to your Dock for quick and convenient access.
- Native iOS Appearance: Preserves the original Dock design, spacing and animations for a seamless experience.
- Smooth Horizontal Navigation: Swipe through your Dock apps using continuous scrolling or page-style navigation, similar to Home Screen pages.
- Customisable Settings: Enable or disable the tweak and apply changes using Apply & Respring in Settings → SlideyDock16.
- Standalone Dock Mode: Disable scrolling and use SlideyDock16 as a traditional 5-icon Dock instead.
- Independent Controls & Layout Memory: Scrolling and Dock layout features have separate switches. Your expanded Dock arrangement is saved when scrolling is disabled and automatically restored when re-enabled.
